- **Нейрика не попала в продукты:** лендинги отдают 403, безопасного горизонтального скрина
  без медицинского контекста в хранилище кадров нет. Нужен источник кадра от владельца
- **Vercel Security Checkpoint** включён на проектах `marklyai.ru`, `voiceiq-delta` и `gvidera.ru`:
  headless-браузер их не открывает (title «Vercel Security Checkpoint», код 11). Живым браузером
  проверить кликом; при желании отключается в настройках Firewall проекта
