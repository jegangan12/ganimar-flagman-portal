# Чек-лист запуска предстартового SEO на один домен

Домен: `________________`  ·  Ответственный: `________`  ·  Дата старта: `__________`

## Этап 1. Техническая база (один вечер)

- [ ] Домен отвечает по HTTPS, сертификат валиден
- [ ] Выбран основной адрес: с `www` или без — второй 301-редиректом на первый
- [ ] Поднят статический хостинг (Vercel / GitHub Pages / Beget)
- [ ] Есть `/blog` с хабом и минимум одной статьёй
- [ ] `robots.txt` отдаёт 200, нет `Disallow: /`
- [ ] `sitemap.xml` отдаёт 200 и содержит все страницы
- [ ] `feed.xml` отдаёт валидный RSS
- [ ] На каждой странице один `<h1>`, canonical, title и description
- [ ] Ссылки на статьи присутствуют в исходном HTML (не только после JS)
- [ ] Микроразметка `BlogPosting` и `BreadcrumbList` проходит валидатор
- [ ] Создан ключ IndexNow, файл `<ключ>.txt` лежит в корне и отдаёт 200
- [ ] Страница 404 не отдаёт код 200

## Этап 2. Панели вебмастера (30 минут)

- [ ] Яндекс.Вебмастер: сайт добавлен, права подтверждены
- [ ] Яндекс.Вебмастер: загружен `sitemap.xml`
- [ ] Яндекс.Вебмастер: главная и статьи отправлены на переобход
- [ ] Яндекс.Метрика: счётчик стоит, вебвизор включён, цели заведены
- [ ] Google Search Console: ресурс добавлен, права подтверждены
- [ ] Google Search Console: отправлен `sitemap.xml`
- [ ] Google Search Console: главная отправлена через «Запросить индексирование»
- [ ] Bing Webmaster Tools: импорт из GSC (опционально, но бесплатно)

## Этап 3. Контент (регулярно)

- [ ] Собрано 20-30 тем в Вордстате и подсказках поиска
- [ ] Темы разложены по неделям на квартал вперёд
- [ ] Публикация раз в неделю, дата в `article:published_time` проставляется честно
- [ ] После каждой публикации: `python3 tools/seo_build.py` и `./tools/indexnow.sh`
- [ ] Раз в две недели: проверка отчёта об исключённых страницах в обеих панелях

## Этап 4. Контроль (раз в месяц)

- [ ] Сколько страниц в индексе Яндекса и Google
- [ ] Первые показы и клики в отчётах панелей
- [ ] Есть ли ошибки обхода, дубли, битые ссылки
- [ ] Какие запросы уже приводят людей — и какие темы дописать под них

## Стоп-сигналы

| Симптом | Что означает | Что делать |
|---|---|---|
| Страниц в индексе 0 через 3 недели | Робот не дошёл или контент признан пустым | Проверить robots, отправить на переобход, нарастить объём текста |
| Индексируется только главная | Нет внутренних ссылок в HTML | Проверить, что список статей не рендерится через JS |
| Страницы выпадают из индекса | Дубли или тонкий контент | Свести дубли canonical, дописать материалы |
| Показы есть, кликов нет | Слабые title и description | Переписать сниппеты под запрос |
