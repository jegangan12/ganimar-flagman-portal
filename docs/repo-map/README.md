# Карта репозитория

Интерактивная изометрическая модель этого репозитория: инфраструктура как объёмная
застройка на сетке, зависимости и payload'ы как реальные пути управления и данных,
каждое утверждение — со ссылкой на файл и строку.

**Открыть:** `docs/repo-map/index.html` — один самодостаточный файл, открывается
двойным кликом, сборка не нужна. В проде доступна по адресу `/docs/repo-map`.

## Что на карте

- **30 построек** — от ворот Vercel до осиротевших изображений в `assets/`
- **38 связей** с payload'ами: загрузка скриптов, `window.GANIMAR_DATA`,
  шесть вызовов `innerHTML`, программные переходы `window.open`
- **9 слоёв** с переключателями видимости
- **4 трассировки** — холодная загрузка, проход рендера, выход в экосистему,
  расхождение с документами
- **14 флагов** — техдолг и места, где README и `docs/` расходятся с кодом

## Управление

| Действие | Как |
|---|---|
| Панорама | перетаскивание |
| Масштаб | колесо мыши, кнопки `+` / `−` |
| Вписать всё | кнопка «Вписать» |
| Досье по узлу | клик по зданию |
| Подписи второго ранга | приблизить (появляются при `k ≥ 0.42`) |
| Шаг трассировки | `←` / `→` |
| Вернуться к обзору | `Esc` |

## Применить к другому репозиторию

Промпт и разбор типовых ошибок — в [`PROMPT.md`](PROMPT.md). В Claude Code есть
слэш-команда: `/repo-3d-map <владелец/репо>`.
