# Плейбук: разгон органики на всех доменах экосистемы GANIMAR

**Дата:** 27 августа 2026
**Принцип:** поисковый возраст домена считается не с даты регистрации, а с первой индексации.
Пустой домен не стареет — он просто лежит. Значит, блог на домене поднимается **в день покупки**,
а не в день релиза сайта.

Практическая часть — в `seo-kit/`: шаблоны, скрипты, чек-лист и правила переноса при релизе.

## 2. Что делается на каждом домене

Порядок одинаковый, разворачивается по `seo-kit/CHECKLIST.md`:

1. `/blog` с хабом и первой статьёй — статический HTML, ссылки видны без JavaScript.
2. `robots.txt`, `sitemap.xml`, `feed.xml`, canonical, микроразметка.
3. Яндекс.Вебмастер + Яндекс.Метрика + Google Search Console, карта сайта загружена,
   страницы отправлены на переобход.
4. Ключ IndexNow в корне и пинг после каждой публикации.
5. Одна статья в неделю по темам из раздела 3.
6. При релизе боевого сайта — перенос по `seo-kit/RELEASE_MIGRATION.md`, адреса статей не меняются.

## 4. График

| Неделя | Что происходит |
|---|---|
| 1 | ganimar.ru — сделано. Разворачиваем `ganimarketing.ru` и `ganimarschool.ru` |
| 2 | Панели вебмастера на всех четырёх доменах, первые статьи опубликованы |
| 3 | `gvidera.ru` и `aimusican.ru`, техминимум на витринах |
| 4+ | Одна статья в неделю на каждый коммерческий домен, замер индексации раз в месяц |

Реалистичная нагрузка: 4 статьи в неделю на четыре домена — это 4-6 часов при использовании
заготовок и разборов из реальных проектов. Если ресурса меньше — режем не регулярность,
а количество доменов: лучше один домен с еженедельной публикацией, чем четыре с публикацией раз в квартал.

## 5. Как мерить, что работает

Раз в месяц по каждому домену фиксируются четыре числа:

- страниц в индексе Яндекса,
- страниц в индексе Google,
- показов в поиске за месяц,
- переходов из поиска за месяц.

Ожидания по срокам: индексация первых страниц — 1-3 недели, первые показы — 3-6 недель,
первые устойчивые переходы по низкочастотным запросам — 2-4 месяца. Всё, что быстрее, — удача,
всё, что медленнее, — повод проверить стоп-сигналы из `seo-kit/CHECKLIST.md`.

## 6. Сделано на ganimar.ru (эталон для остальных доменов)

- `/blog` — хаб со списком материалов в статическом HTML
- 4 статьи по 700-1500 слов с микроразметкой `BlogPosting`, `BreadcrumbList`, `FAQPage`
- `robots.txt`, `sitemap.xml`, `feed.xml`, canonical на всех страницах
- Ключ IndexNow в корне и скрипт пинга `tools/indexnow.sh`
- Генератор карты сайта и фида `tools/seo_build.py` — запускается после каждой публикации
- Карточки блога на главной ведут на внутренние страницы, а не во внешний Telegram-канал,
  и отдаются в исходном HTML без JavaScript

**Осталось сделать руками** (доступа к панелям у репозитория нет):
подтвердить права в Яндекс.Вебмастере и Google Search Console, загрузить карту сайта,
отправить страницы на переобход. Инструкция — в `seo-kit/README.md`, шаг 7.
