# Дизайн-система зонтичного бренда GANIMAR (Design System v1.0)

Дизайн-система задает единый премиальный визуальный код для ствола экосистемы (`ganimar.ru`) и всех дочерних проектов (`ganimarketing.ru`, `ganimarschool.ru`, `aimusican.ru`, витрины и поддомены).

---

## 1. Концепция и эстетика: "Warm Obsidian & Amber Luxury"

Стиль сочетает строгость и технологичность премиального темного интерфейса (Obsidian Dark) с теплотой пергаментных оттенков (Warm Parchment) и глубоким янтарно-золотым свечением (Amber Aura).

### Ключевые принципы эстетики:
1. **Премиальность без визуального шума:** много воздуха, математически выверенные отступы, чистая иерархия.
2. **Тактильность и глубина:** многослойность интерфейса через полупрозрачные стеклянные панели (Frosted Glass / Glassmorphism), мягкие внутренние фаски (`inset 0 1px 0 rgba(255,255,255,0.12)`) и диффузные тени.
3. **Живая интерактивность:** фоновое созвездие на Canvas, реагирующее на движение курсора, плавные микро-ховеры, градиентные обводки карточек при наведении.
4. **Анти-слоп гарантия:** шрифты подобраны под безупречную кириллицу (`Unbounded` + `Onest` / `Manrope`), отсутствие шаблонных стоковых картинок, доказательная графика и авторские фото-композиции.

## 2. Цветовая палитра (Color Tokens)

Дизайн-система использует современное цветовое пространство `OKLCH` с fallback на `HEX/RGBA` для максимальной чистоты и насыщенности оттенков на экранах Retina/P3.

### Основные фоны и поверхности (Dark / Warm Obsidian)
```css
:root {
  /* Базовые фоны */
  --color-bg:            oklch(0.14 0.012 60);    /* #0E0D11 - глубокий теплый обсидиан */
  --color-bg-alt:        oklch(0.17 0.014 62);    /* #141318 - приподнятый фон секций */
  --color-surface:       oklch(0.21 0.016 58);    /* #1B1A20 - карточки и панели */
  --color-surface-glass: rgba(27, 26, 32, 0.72);  /* полупрозрачное стекло */
  --color-surface-hover: oklch(0.25 0.018 56);    /* карточка при наведении */
  
  /* Разделители и границы */
  --color-border:        oklch(0.30 0.018 60 / 0.5);  /* тонкие границы */
  --color-border-glow:   oklch(0.815 0.150 76 / 0.3); /* светящаяся граница */

  /* Текстовые градации */
  --color-ink-primary:   oklch(0.97 0.010 80);    /* #F8F7FA - основной текст */
  --color-ink-secondary: oklch(0.80 0.016 72);    /* #C5C3CB - подзаголовки, описания */
  --color-ink-muted:     oklch(0.62 0.018 66);    /* #8E8C96 - второстепенные подписи */
  --color-ink-faint:     oklch(0.44 0.018 64);    /* #5B5963 - неактивные элементы */
}
```

### Акцентные цвета зонтика (Brand Accents)
```css
:root {
  /* Янтарно-золотой (Мастер-бренд и Маркетинг) */
  --color-accent-amber:      oklch(0.815 0.150 76);    /* #E8A13C - главный акцент */
  --color-accent-amber-dark: oklch(0.720 0.165 58);    /* #C87B18 - градиентный партнер */
  --color-accent-amber-glow: rgba(232, 161, 60, 0.35); /* свечение */
  --color-accent-ink:        oklch(0.20 0.05 70);      /* темный текст на кнопке */

  /* Неоново-фиолетовый (ИИ-лаборатория и автоматизация) */
  --color-accent-violet:      #8B7CFF;
  --color-accent-violet-soft: #A99DFF;
  --color-accent-violet-glow: rgba(139, 124, 255, 0.35);

  /* Изумрудный (Live-статус и метрики) */
  --color-status-live:       oklch(0.80 0.135 158);    /* #4ADE80 */
  --color-status-live-glow:  rgba(74, 222, 128, 0.30);
}
```

## 3. Типографика (Typography Scale)

### Шрифтовые гарнитуры:
1. **Display Font (Заголовки, цифры, бейджи):** `Unbounded`, sans-serif.  
   *Характер:* футуристичный, геометричный, уверенный, выделяющий ключевые смыслы.
2. **Body Font (Основной текст, карточки, интерфейс):** `Onest`, `Manrope`, system-ui, sans-serif.  
   *Характер:* превосходная читаемость кириллицы, нейтральный, премиальный.

### Иерархия размеров (Fluid Clamp Scale):
- **Hero Display H1:** `clamp(2.4rem, 4vw + 1.2rem, 4.4rem)` / `line-height: 1.05` / `letter-spacing: -0.035em`
- **Section H2:** `clamp(1.8rem, 2.5vw + 0.8rem, 2.8rem)` / `line-height: 1.15` / `letter-spacing: -0.025em`
- **Card H3:** `clamp(1.2rem, 1.2vw + 0.5rem, 1.5rem)` / `line-height: 1.25`
- **Big Numbers / Stats:** `clamp(2.2rem, 3.5vw + 0.8rem, 3.8rem)` / `font-weight: 700`
- **Body Regular:** `clamp(15px, 0.4vw + 13px, 17px)` / `line-height: 1.6`
- **Body Small / Captions:** `13px - 14px` / `line-height: 1.5`
- **Badge / Label:** `11px - 12px` / `font-weight: 600` / `letter-spacing: 0.04em` / `text-transform: uppercase`

## 4. Компонентная система (UI Components)

### 4.1. Кнопки (Buttons)
- **Primary Amber Button:** градиентная заливка `linear-gradient(135deg, var(--color-accent-amber), var(--color-accent-amber-dark))`, контрастный темный текст, радиус `999px`, мягкая тень свечения, микро-смещение при нажатии `transform: translateY(-1px) scale(1.02)`.
- **Glass Secondary Button:** полупрозрачный фон `rgba(255,255,255,0.06)`, тонкая рамка `1px solid rgba(255,255,255,0.12)`, ховер с мягким подсвечиванием.
- **Icon Action Button:** круглая или скругленная кнопка `44x44px` для копирования контактов, переходов и соцсетей.

### 4.2. Стеклянные карточки (Liquid Glass Cards)
- Скругление: `20px - 24px` (`border-radius: var(--radius-card)`).
- Подложка: `backdrop-filter: blur(20px) saturate(160%)`.
- Фон: многослойный линейный градиент с прозрачностью `rgba(27,26,32,0.65)`.
- Верхний блик: `box-shadow: inset 0 1px 0 rgba(255,255,255,0.15)`.
- Градиентная рамка при наведении: эффект бегущего света или мягкого янтарного контура.

### 4.3. Карточки веток зонтика (Tree Branch Cards)
- Интерактивный заголовок с иконкой-глифом.
- Бейдж статуса (`Активен`, `Флагман`, `Платформа`, `Медиа`).
- Описание ценности в 2 предложениях.
- Кнопка перехода со стрелкой `→` и обратным эффектом сшивки.

### 4.4. Статистические плашки (Stats Tiles)
- Огромная цифра с акцентным цветом и плавной анимацией нарастания при скролле.
- Четкая проверяемая подпись (доказательство).
- Тематическая микро-иконка или индикатор динамики.

### 4.5. Диалоговые модальные окна (Friendly Modals)
- Анимированное появление с легким масштабированием.
- Дружелюбный заголовок с эмодзи.
- Контент вставляется строго через безопасный `textContent`.
- Кнопка быстрого закрытия по крестику, клавише `Escape` и клику вне окна.

## 5. Эффекты и микро-анимации (Motion Design)

1. **Constellation Canvas:** на заднем плане летают интерактивные частицы с мягкими соединительными линиями, плавно притягивающиеся к курсору мыши.
2. **Scroll Reveal:** элементы плавно появляются с небольшим смещением снизу вверх по мере прокрутки (`IntersectionObserver`).
3. **Ticker / Counter:** живой счетчик цифр на первом экране и в блоке доказательств.
4. **Interactive Tab Pills:** мгновенное переключение категорий кейсов и продуктов без перезагрузки страницы.
5. **Accessibility Respect:** поддержка `@media (prefers-reduced-motion: reduce)` с мгновенным показом без анимаций для пользователей с чувствительным вестибулярным аппаратом.
