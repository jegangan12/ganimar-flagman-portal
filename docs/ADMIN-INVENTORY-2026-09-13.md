**Известные грабли из decisions/retrospectives**
- Журнал не имеет права ронять бизнес-логику; хендлер зацикливается, если не исключить свои логгеры (Marqly `INVENTORY.md:89-90`, Музограф `logging_setup.py:23`).
- `track_visit` вызывалась 3-4 раза на страницу → «4 стр. · 6 мин» вместо 1 стр. · 2 мин; длительность брать max, не сумму; страницы считать по смене пути (Нейрика `db/analytics-04.sql`, Р-104).
- Три версии plpgsql-функции с разными сигнатурами → `function is not unique`, события с UTM не писались вовсе (`db/analytics-05.sql`).
- Заходы владельца засоряют статистику - кука `neyrika_owner=1` при входе в админку; iframe-подложка карты кликов не должна считаться просмотром (`site/lib/track.ts:26-60`).
- Яндекс.Метрика: включать только после политики, баннера и уведомления РКН; вебвизор - самая чувствительная часть; юрстатус зависит от состава данных, а не от того, чей инструмент (Р-37, Р-38 в `Лендинг-Школьная-программа/decisions.md:224-300`).
- Обещание в политике ≠ механизм: `prune_recordings()` существовала, но не вызывалась ниоткуда - предписания выносят за несоответствие документу (`db/retenciya-01.sql`).
- Ретенция вызывается **после** снятия бэкапа и пишет строку в журнал: молчаливое удаление не лучше молчаливого сбоя (Р-92).
- Цифра от модели должна быть подписана рядом с собой, не в tooltip (Marqly решение 29); отчёт - «все цифры считает код из событий» (Ясно `USER-GUIDE.md:191-193`).
- Себестоимость, вбитая константой, дала «маржу 97%» при убытке в 50 раз - цену выводить из факта покупки + тест-сторож (Aimagenarium `decisions.md:47-53`).
- Server actions идут под сервисной ролью, RLS их не ограничивает - гард последнего суперадмина только триггером в БД (Launch Market 0016, Marqly `INVENTORY.md:91-92`).
- Не давать стартовать в проде с DEBUG=true или секретом короче 32 символов (Aimagenarium `backend/app/core/config.py:141`, Marqly `INVENTORY.md:101-103`).
- Vercel: диапазон `216.198.79.x` не открывается из России, нужен `76.76.21.21` (Marqly `INVENTORY.md:96-98`) - критично для ganimar.ru до переезда на VPS.
- Кириллица в пути (`ПРОГРАММИРОВАНИЕ (разработки)`) вешает `tsc`/docker build - Marqly `INVENTORY.md:99-100`; `git archive` висит в iCloud-папке (Музограф `CLAUDE.md`).
- Выкат rsync-ом из файлов, а не из git → двое суток сайт отдавал демо-ветку; выкат только скриптом с проверкой ветки и живого сайта после (`projects/neyrika-landing/CLAUDE.md:57-68`, Р-89).
- Payload CMS не пушит схему в прод (`NODE_ENV=production`) - новые поля вручную (Музограф `CLAUDE.md`) - аргумент против Payload для ganimar.ru.
- Пароли: «показать мой пароль» невыполнимо by design, UX вокруг замены; дефолтные пароли из dev-скриптов утекают в доки (Launch Market `tech-status-learnings.md:23-24`).
- Статус в карточке проекта - снимок на дату, а не факт: карточка `ganimar-ru-flagman/README.md` говорит «сайта нет», Нейрика полгода «ждала сервер» уже работая (`projects/neyrika/CLAUDE.md:34-37`). Перед проектированием сверить живое состояние ganimar.ru с агентами `blog-fix`/`home-fix`.
