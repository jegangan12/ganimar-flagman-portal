## 🎨 Дизайн-система *"Warm Obsidian & Amber Luxury"*
- **Цветовая модель:** OKLCH токены (теплый обсидиан `oklch(0.135 0.012 55)`, янтарное золото `oklch(0.815 0.150 76)`, электрик-фиолет `#8B7CFF`, изумруд `oklch(0.80 0.135 158)`).
- **Типографика:** `Unbounded` (геометрический дисплейный акцент) + `Onest` (чистый удобочитаемый гротеск).
- **Стекломорфизм:** многослойные фаски, градиентная обводка с мягким угловым свечением.
- **Hero-фрейм:** вдохновлен фотографическим референсом Dan с угловыми янтарными засечками и студийным портретом на глубоком черном фоне.

## ⚡ Технологический стек
- Независимый статический стек: **HTML5 + Modern CSS + ES6 JavaScript**.
- Без тяжелых внешних фреймворков (быстрый First Contentful Paint < 0.4s).
- Интерактивный Canvas-фон созвездий с реакцией на курсор.
- Год в футере вычисляется скриптом (`<span id="year"></span>`).
- Полная семантика: Schema.org `Person`, Open Graph, XSS-защита через безопасный `textContent`.
