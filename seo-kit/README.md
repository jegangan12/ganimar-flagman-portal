# SEO-кит: предстартовый блог на любом домене за один вечер

Набор файлов, который превращает купленный, но ещё не запущенный домен из «пустого места»
в индексируемый сайт с историей. Логика простая: **поисковики считают возраст сайта не с даты
регистрации домена, а с первой индексации**. Пока на домене ничего нет — счётчик доверия не идёт,
и в день релиза проект стартует с нуля.

Кит собран на живом примере — блоге `ganimar.ru/blog` в этом же репозитории.

---

## Что внутри

| Файл | Назначение |
|---|---|
| `template/index.html` | Хаб блога (`/blog/index.html`). Самодостаточный: стили внутри файла, зависимостей нет |
| `template/article.html` | Шаблон статьи (`/blog/<slug>.html`) с микроразметкой `BlogPosting` и хлебными крошками |
| `template/robots.txt` | Разрешает обход, указывает карту сайта |
| `seo_build.py` | Генерирует `sitemap.xml` и `feed.xml`, читая метатеги готовых страниц |
| `indexnow.sh` | Пингует Яндекс и Bing о новых страницах через IndexNow |
| `CHECKLIST.md` | Пошаговый чек-лист запуска на один домен |
| `RELEASE_MIGRATION.md` | Как перенести накопленное на боевой сайт и не обнулить фору |

## Развёртывание за 40-60 минут

1. **Скопировать структуру** в репозиторий домена:
   ```
   blog/index.html          ← template/index.html
   blog/pervaya-statya.html ← template/article.html
   robots.txt               ← template/robots.txt
   tools/seo_build.py       ← seo_build.py
   tools/indexnow.sh        ← indexnow.sh
   ```

2. **Заменить плейсхолдеры** во всех скопированных файлах:
   `{{DOMAIN}}`, `{{BRAND}}`, `{{AUTHOR}}`, `{{TOPIC}}`, `{{TITLE}}`, `{{DESC}}`, `{{H1}}`,
   `{{LEAD}}`, `{{SLUG}}`, `{{CATEGORY}}`, `{{READ}}`, `{{DATE}}`, `{{DATE_HUMAN}}`, `{{CTA_URL}}`.
   В `tools/seo_build.py` поправить блок `CONFIG`.

3. **Написать первую статью.** Не «о компании», а ответ на запрос будущего клиента.
   Минимум 700 слов, один H1, подзаголовки H2 под конкретные вопросы.

4. **Сгенерировать карту сайта и фид:**
   ```bash
   python3 tools/seo_build.py
   ```

5. **Создать ключ IndexNow** (один раз на домен):
   ```bash
   KEY=$(python3 -c "import secrets;print(secrets.token_hex(16))"); printf '%s' "$KEY" > "$KEY.txt"
   ```

6. **Задеплоить.** Подойдёт любой статический хостинг: Vercel, GitHub Pages, Beget.
   Для Vercel — `{"cleanUrls": true, "trailingSlash": false}`, тогда адреса будут `/blog/slug` без `.html`.

7. **Подключить панели вебмастера** — без этого шага поисковики о домене просто не узнают:
   - Яндекс.Вебмастер: добавить сайт, подтвердить права (метатег или файл в корне),
     загрузить `sitemap.xml`, включить обход по счётчику и переобход страниц.
   - Google Search Console: добавить ресурс (домен или префикс URL), подтвердить,
     отправить `sitemap.xml`, проверить главную через «Проверка URL» → «Запросить индексирование».
   - Дополнительно: Bing Webmaster Tools импортирует данные из GSC в два клика.

8. **Пингануть IndexNow:**
   ```bash
   ./tools/indexnow.sh
   ```

9. **Поставить регулярность:** одна статья в неделю, каждый раз повторяя шаги 4 и 8.

## Проверка, что всё сделано правильно

```bash
curl -sI https://ДОМЕН/robots.txt | head -1          # 200
curl -s  https://ДОМЕН/sitemap.xml | grep -c "<loc>"  # число страниц
curl -s  https://ДОМЕН/blog | grep -c "<a "           # ссылки на статьи есть в HTML, а не только в JS
```

Последняя проверка — ключевая. **Если ссылки на статьи появляются только после выполнения
JavaScript, для Яндекса их фактически нет.** Список материалов должен лежать в исходном HTML.

---

## Чего в ките сознательно нет

- Заглушки «сайт в разработке» — индексировать там нечего, возраст не идёт.
- `noindex` «до релиза» — это тот же ноль, только с ощущением проделанной работы.
- Массовой генерации текстов — пачка несверенных статей ставит домену метку низкого качества
  ещё до запуска.
