## Критичные грабли

- Автоматические проверки прода с одного IP → через ~35 запросов Vercel отдаёт 403
  `x-vercel-mitigated: challenge` на все проекты аккаунта; для мира сайт открыт → проверять редко
  или с другого адреса, тревогу владельцу нести только после проверки с независимой точки
- Картинки в сессии: после одного скриншота выше 2000 px все дальнейшие чтения изображений
  отклоняются до конца сессии → снимать в масштабе css и не выше 1800 px, приёмку вести OCR
  (`swift` + Vision) и замерами DOM через CDP
- Агенты-исполнители падают на лимите API молча, «начинаю» и тишина → результат агента считать
  полученным только по файлам на диске и своим замерам
- Кириллица в пути `ПРОГРАММИРОВАНИЕ (разработки)` вешает `tsc` и docker build → код админки
  заводить в ASCII-пути, например `~/dev/ganimar-admin/`, как сделано для jarvis, signum, ideum
